💰 Platform Donasi *wajib

Pilih platform donasi yang kamu pakai, dan masukkan API key / stream key-nya.

Stream key Saweria: Dashboard Saweria → Settings → Stream Key.
API key Trakteer: Trakteer → Pengaturan → Integrasi.

🌐 Hubungkan Webhook *wajib

Ini URL publik untuk menerima notifikasi donasi. Paste ke pengaturan webhook di platform donasimu.

Membuka tunnel ngrok...

Masuk ke dashboard Saweria/Trakteer → cari menu Webhook/Integrasi → tempel URL di atas.
